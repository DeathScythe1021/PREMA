Manual

  1. 01Scope本目錄收錄 __COUNT__ 種美術風格，作為設計參考之用。各風格之版面、字體、圖形及禁用事項均已明訂，可據以辨識與執行。
  2. 02Procedure瀏覽參考圖，選定風格；於風格頁取用英文 prompt、背景色與配色；如需製作簡報，複製指令貼至 Claude。
  3. 03Colour重點色數量依風格設有上限。自訂顏色須通過對比檢查，文字與背景之對比不得低於 4.5:1。
  4. 04Prompts每一風格附英文 prompt，可用於圖像生成工具，或作為設計提案之風格說明。
  5. 05Sources風格名稱整理自公開的設計影片與文章，來源持續增加，各風格頁註明出處；參考圖取自 Pinterest，著作權屬原作者。

How to use

  1. 01Browse瀏覽參考圖。點圖片可放大檢視，以左右鍵切換。
  2. 02Open點 Use this style，打開風格面板。
  3. 03Preview於 Preview 選擇背景與配色，範例會即時更新；按 Shuffle 可重新分配顏色。
  4. 04Specification於 Specification 查看版面、字體與禁用事項。
  5. 05Prompt於 Prompt 右上角複製英文 prompt，可貼入生成工具。
  6. 06Slides如需製作簡報，於 Make slides with Claude 複製指令。
