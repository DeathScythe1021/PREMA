# 去 AI 感檢查清單

AI 做的簡報常有一種「平均值」的樣子：每個決定都選最安全、最常見的選項。結果就是一看就知道是模板。下面每一條都是常見的平均值，以及該怎麼換成有立場的選擇。

完成簡報後逐條檢查。風格 JSON 明確要求的東西（例如 Glassmorphism 的毛玻璃、Neo Frutiger 的光澤）不算違規，但仍要做得有理由。

## 版面

- [ ] **不要什麼都置中。** 置中是最省事的選擇。照風格的 `layout` 決定對齊：瑞士式靠左、侘寂不對稱、收據置中但只有收據置中。
- [ ] **不要預設三欄卡片。** 「三個圓角卡片，每個上面一個圖示、一個標題、兩行字」是最常見的 AI 版面。改用表格、大數字、時間軸、分格，或拆成三頁。
- [ ] **每頁只講一件事。** 條列超過 4 點就拆頁。
- [ ] **標題位置要固定。** 同一類頁面的標題在同一個位置，翻頁時不會跳。
- [ ] **留白要有用意。** 不是每個空位都要填東西；也不是平均分散。

## 視覺

- [ ] **不要隨手加漸層。** 尤其是紫到藍、粉到橘的對角漸層和模糊光球。只有風格需要時才用（Astro Attic 的天空、Blurry Motion 的色塊）。
- [ ] **不要每個框都圓角加陰影。** 圓角與陰影要跟著風格：粗野主義是硬邊位移陰影，瑞士風沒有陰影，擬物化才有寫實陰影。
- [ ] **不要用表情符號當圖示。** 也不要「圓形底色裡放一個線條圖示」那種通用圖示組。需要圖形就照風格的 `motifs` 畫。
- [ ] **風格的招牌元素要真的出現。** Postage 要有齒孔與郵戳、ASCII 要有字元框線、Receiptify 要是一張收據。只套顏色和字體，看起來還是 AI 模板。
- [ ] **顏色不要超過風格上限。** 也不要每頁換一種重點色。

## 字體

- [ ] **用風格指定的字體。** 不要退回 Inter、Roboto、系統預設字。
- [ ] **字級最多五級。** 用字重、斜體、顏色做強調，而不是再多一個字級。當成圖形用的巨大裝飾字（Swiss Punk 的裁切數字、Modular Typography 的拼字，加 `aria-hidden="true"`）不算在內。
- [ ] **中文要有中文字體，順序是西文在前、中文在後。** 例如 `font-family: "Schibsted Grotesk", "Noto Sans TC", sans-serif;`。中文字型放前面的話，標題裡的英文、數字會用中文字型內建的西文字形，風格就跑掉了。

## 文字內容

- [ ] **不要空泛的形容詞。** 「打造卓越體驗」「賦能」「無縫接軌」這類詞換成具體做了什麼。
- [ ] **不要編造數字與引言。** 使用者沒給的數字用 `[待補]` 標出來。從使用者的數字算出來的值（差額、占比、成長數）可以用，但要寫進講者備註，交付時也告訴使用者哪些是算出來的。
- [ ] **真實人物、作品、年份要查證。** 講者簡介、作品名稱、生卒年這類事實，沒把握就寫 `[待補]`；有把握的也要在交付時列出來，請使用者查證。
- [ ] **自己加的文案要交代。** 為了風格加的標籤（收據的 QTY、登機證的 SEAT）沒問題；但帶有說法或立場的句子（「2027 也請多多指教」），交付時列出來請使用者確認。
- [ ] **標題寫成一句話或一個名詞，全份統一。** 不要一頁是問句、一頁是口號、一頁是名詞。
- [ ] **不要「不只是 A，更是 B」這類句型。** 直接說 B。
- [ ] **繁體中文用台灣用語與全形標點。** 有 `speak-human-tw` skill 的話用它檢查一次。

## 圖片

- [ ] **沒有使用者給的圖，就用版位。** 不生成圖片、不放圖庫照片、不用隨機佔位圖服務。
- [ ] **版位外觀要符合風格。** 不是一個灰色方框加「Image」。
